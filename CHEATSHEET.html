Tool calling

@tool
def get_stock(sku: str) -> int:
    'Units in stock for a SKU.'   # docstring = when to use
    return {...}.get(sku, 0)

m = llm.bind_tools([get_stock]).invoke("Hauler stock?")
m.tool_calls   # model REQUESTS the call (no result yet)

Close the loop

msgs = [HumanMessage(q), m]
for tc in m.tool_calls:
    msgs.append(get_stock.invoke(tc))  # -> ToolMessage
llm_with_tools.invoke(msgs).content    # final answer
Key: the model only asks — you run the tool & feed it back. LangGraph automates this.

LangGraph Studio terminal

langgraph dev   # opens the visual IDE
Submit a query → watch agent → tools → agent, open a node to see state, then fork & replay.

LangChain vs LangGraph

LangChainlinear chain (DAG), one pass, predictable
LangGraphgraph with loops + state, branching, HITL
Rule: LangChain for linear chains; LangGraph the moment you need loops, state, or branching.

Notebook 02
LangGraph — stateful agents

1 · State graph from scratch

from langgraph.graph import StateGraph, START, END
g = StateGraph(State)
g.add_node("write", write); g.add_node("critique", critique)
g.add_edge(START, "write"); g.add_edge("write", "critique")
g.add_edge("critique", END)
app = g.compile(); app.invoke({"topic": ...})

2 · Conditional edges (branching)

def router(s): return "math" if ... else "chat"
g.add_conditional_edges("classify", router,
                        {"math":"math","chat":"chat"})

3 · ReAct agent (the loop, automated)

from langchain.agents import create_agent
agent = create_agent(llm, tools=[inventory, price])
agent.invoke({"messages":[("user", q)]})

4 · Memory (checkpointer)

from langgraph.checkpoint.memory import MemorySaver
agent = create_agent(llm, tools, checkpointer=MemorySaver())
cfg = {"configurable": {"thread_id": "1"}}
agent.invoke({"messages":[("user", q)]}, cfg)  # remembers

5 · Human-in-the-loop

agent = create_agent(llm, tools, checkpointer=MemorySaver(),
                     interrupt_before=["tools"])   # pause
agent.invoke({...}, cfg)               # stops before tool
agent.get_state(cfg).next              # ('tools',)
agent.invoke(None, cfg)                # approve -> resume
Note: use create_agent (not the deprecated create_react_agent).
