#ToolRunSay / show · gotcha
1 LangChainFoundation python demos/01_langchain.py One API over any model; prompt | model | parser composes; tool-calling powers every agent layer. Show LCEL, tool_calls, streaming.
2 LangGraphOrchestration python demos/02_langgraph.py Chains are DAGs; agents need loops + durable state. Checkpointer is why Q2 ("the Scout?") answers from memory.
3 LangGraph StudioShip & Debug langgraph dev Visual IDE for agents — pick agent graph, submit a query, watch agent→tools→agent, fork & replay a node. Gotcha: if 3.13 fails, use 3.11/3.12 or play the GIF.
4 LangServeShip & Debug python demos/04_langserve.py Any runnable → REST API. Open /joke/playground/ + /docs, then curl /joke/invoke. Prod path = LangGraph Platform. Needs 2nd terminal.
5 LangMemMemory & Data python demos/05_langmem.py Checkpointer remembers a thread; LangMem remembers the user — extracts durable facts to reuse across sessions.
6 LangExtractMemory & Data python demos/06_langextract.py Structured extraction grounded to exact source spans — auditable, not just "return JSON". Show span=. Gotcha: pre-run this one; Gemini-key fallback in docstring.
7 LlamaIndexMemory & Data python demos/07_llamaindex.py RAG engine: ingest→embed→index→query with sources. Remote LLM + local embeddings (OpenRouter has none).
8 DSPyOptimize python demos/08_dspy.py Don't hand-tune prompts — declare a Signature, let the teleprompter compile few-shot demos. Show before/after + inspect_history. ~20–40s, several calls.
9 CrewAIMulti-Agent python demos/09_crewai.py Role-based team: role·goal·backstory, tasks flow Analyst→Writer. Show verbose logs + final summary.
10 AutoGenMulti-Agent python demos/10_autogen.py Conversational topology — writer↔critic iterate until "APPROVE". model_info required to drive non-OpenAI models.
11 LangSmithObservability python demos/11_langsmith.py 3 env vars → every LC/LG run auto-traced. Open smith.langchain.com, expand tree: latency/tokens/cost. Callback: re-run demo 2, it appears here.
12 LangfuseObservability python demos/12_langfuse.py OSS, framework-agnostic, self-hostable. Callback or @observe + custom score. Open cloud.langfuse.com → Traces. Must flush() before exit (script does).
